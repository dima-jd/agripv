# AGRIPV

Reviewed public static site for https://agripv.spfi.co.il. Publish the main branch root with GitHub Pages.

This repository contains public website output only. Editorial drafts, private source bundles and credentials are excluded. Content and image rights remain with their respective owners; this repository does not grant a blanket reuse license.

Newsletter signup and private contact require owner-configured services. Map layers are dated evidence and modelled potential, not a live operating-status feed.

Data in `data/` is produced by SPFI's data pipeline and updated through pull requests. The map's "How to read this map" panel lists each dataset's date, source and terms of use.
